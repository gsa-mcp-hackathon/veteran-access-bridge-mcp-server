# Backend scripts

Start with [MCP discovery](list_local_mcp_tools.py) for a credential-free check of the installed server. [Local setup](setup-local.sh) and the [PowerShell equivalent](setup-local.ps1) document developer startup. The [data-source examples](data-sources/README.md) and [synthetic cohort utilities](synthea/README.md) have separate requirements.

Scripts beginning with `accept_`, `prepare_`, `verify_` or `deploy-` target specific test or hosted environments. Read their arguments and expected side effects before use. The judge walkthrough starts with [local tests](../tests/README.md).
