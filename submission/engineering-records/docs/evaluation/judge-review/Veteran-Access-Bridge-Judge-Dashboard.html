DIRECT MCP EVALUATION · NOVEMBER 19, 2026

Did the server find the right options?

For a separate test case, we specified the correct answers in advance and called the tools directly. Phoenix compared the relevant fields in each response with those answers using exact equality.

3 slots

The fixture contained three candidates for an established patient’s 30-minute, in-person follow-up.

2 eligible

One slot failed three checks involving patient classification, visit purpose and scheduling template. A patient preference could not override eligibility.

14 days

The earliest eligible option was within this fixture’s 20-day threshold. Reviewing options created zero bookings.

How to interpret 16/16
All 16 assertions matched across four MCP tools. Several questions inspect different fields from the same encounter. This is one known Primary Care case plus an unknown-case check. Voice quality, population-wide accuracy, latency and the deployed spoken identity check require separate measurements.
